# ADR 0007: A6 Token instead of 58mm thermal slip

OT and Spectacles to be made deferral print a Token on A6 (105 × 148 mm) using a normal inkjet or laser printer. The 58mm thermal slip is retired.

## Rejected alternatives

- Keep 58mm thermal — needs a dedicated printer we are not standardising on in the field.
- A4 Token — wasteful; the Token is a take-home reminder, not a prescription.
- A second on-the-day queue ticket — the Token printed at deferral is the paper they bring.
